# رفيق الصحة — Health Tracker v2

تطبيق عائلي لتتبع الجرعات والأدوية والصحة: **سطح مكتب + موبايل + نسخة أونلاين متزامنة**،
بواجهة عربية RTL بالكامل، يعمل أوفلاين ويتزامن عند الاتصال.

## المعمارية

```
src/
├── core/          # طبقة نقية بلا React/Dexie/Capacitor (قاعدة ثابتة)
│   ├── schema/    #   المخطط والأنواع + سياسات افتراضية
│   ├── engine/    #   doseEngine (جدولة/فائت) + inventory (foldBalance/projectStock/dosesRemaining)
│   ├── notify/    #   policy.ts — أوضاع الوالدة/المالك + العتبات المتدرجة
│   ├── sync/      #   outbox + النسخ الاحتياطية المشفرة (AES-GCM)
│   ├── ai/        #   تجريد المزودين + حماية + طابور
│   ├── barcode/   #   محلل GS1 DataMatrix/QR/EAN
│   └── time/      #   زمن بمنطقة توقيت العائلة
├── data/          # محوّلات: Dexie (IndexedDB) + جلسة + إشعارات + مزامنة
├── features/      # today · meds (مسح علبة) · inventory · labs (AI + شات) · journal · trash · more
├── modes/         # وضع الوالدة / وضع المالك
├── ui/            # مكونات RTL
└── app/           # الهيكل والتهيئة
api/               # Vercel Functions: auth · sync · push · ai · backup · cron · health
tests/             # 77 اختبار vitest لكل محرك وسياسة
```

**قواعد البيانات:**
- محلياً: Dexie/IndexedDB، والأحداث (جرعات/مخزون) **append-only**.
- سحابياً: Neon (Postgres) — كل صف مرتبط بـ `family_id` (عزل كامل بين العائلات).
- الحذف **ناعم** دائماً (`deletedAt`) + سلة محذوفات 30 يوماً، والسجل التاريخي لا يُمسح.
- كل تعديل يمر عبر **outbox** يتزامن ثنائي الاتجاه بمؤشر رتيب `server_seq` + audit log.

## الأمان
- حسابات عائلة (مالك/والدة/عضو) — كلمات المرور scrypt، جلسات JWT (15د/60يوم) بتجديد تلقائي.
- كل مسارات `/api/*` (عدا التسجيل/الدخول) محمية، وكل استعلام مفهوم بـ `family_id`.
- النسخ الاحتياطية تُشفَّر **على الجهاز** (AES-256-GCM بمفتاح PBKDF2 من كلمة مرور تختارها) —
  السيرفر يخزّن نصاً مشفّراً لا يستطيع فكه.
- AI: المفاتيح على السيرفر فقط، موافقة صريحة قبل كل إرسال، تنقية معرفات/هواتف،
  سقف يومي لكل عائلة، ومطالبة نظام تمنع التشخيص/تغيير الجرعات.

## النشر (Vercel + Neon)

1. أنشئ مشروع Neon جديد وانسخ **Connection string (pooled)**.
2. اربط المستودع بـ Vercel — سيكتشف `vercel.json` تلقائياً (build: `vite build`، functions من `api/`).
3. أضف متغيرات البيئة في Vercel:
   - `DATABASE_URL` — سلسلة Neon.
   - `AUTH_SECRET` — `node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"`.
   - اختياري: `GEMINI_API_KEY` (من [aistudio.google.com/apikey](https://aistudio.google.com/apikey) — الطبقة المجانية)،
     `GROQ_API_KEY` / `OPENROUTER_API_KEY` كبديل، و`FCM_PROJECT_ID/CLIENT_EMAIL/PRIVATE_KEY` للـ Push.
4. افتح `/api/health` للتأكد: `{ok:true, db:true, ...}`.

> ملاحظة: فحص الجرعات الفائتة يعمل على جهاز المستخدم عند فتح التطبيق (كل 5 دقائق
> وعند العودة للتطبيق). أضفت نقطة `/api/cron/missed` كشبكة أمان إضافية على السيرفر،
> وهي معطلة افتراضياً؛ لتشغيلها على خطة Pro أضف إلى `vercel.json`:
> `"crons": [{ "path": "/api/cron/missed", "schedule": "0 3 * * *" }]`
> (خطة Hobby لا تدعم crons متكررة وقد يرفض النشر معها).

## حزمة الموبايل (Android APK) — Capacitor

```bash
npm run build
npx cap add android          # مرة واحدة
# عدّل server.url في capacitor.config.ts إلى عنوان Vercel الخاص بك
npm run cap:sync
npx cap open android         # ثم Build APK من Android Studio
```

صلاحيات مطلوبة بـ AndroidManifest (تُضاف تلقائياً عند `cap add`): إشعارات، منبّهات دقيقة، كاميرا.
أيقونة الحبة الدوائية: `resources/icon.svg` ثم `npm run icons` (يتطلب `@capacitor/assets`).

## سطح المكتب (EXE/DMG) — Tauri

```bash
npm run build
cd src-tauri && cargo tauri build   # يتطلب Rust — أنتج NSIS (.exe) و DMG
```

**قرار offline/online:** تطبيق الويب والموبايل يفتحان النسخة الأونلاين وتُخزَّن البيانات محلياً
(Dexie) وتتزامن عند الاتصال — أي يعمل أوفلاين ويتزامن تلقائياً. نسخة Tauri تُغلّف ملفات `dist/`
ثابتة (أوفلاين كلياً) مع تعيين `serverBase` من «المزيد» للاتصال بالسيرفر عند الحاجة.
أثر ذلك على الإشعارات: المنبّه المحلي يعمل داخل التطبيق المفتوح؛ عند إغلاقه يعتمد
Push (ويب/موبايل) أو إشعارات Tauri الأصلية (سطح المكتب).

## مفاتيح مجانية
- **Gemini**: aistudio.google.com/apikey → متغير `GEMINI_API_KEY` (يقرأ الصور و PDF — الأشعة تعمل به).
- **FCM**: console.firebase.google.com → Project settings → Service accounts → مفتاح JSON →
  `FCM_CLIENT_EMAIL` و`FCM_PRIVATE_KEY` و`FCM_PROJECT_ID`.

## قيود موثقة
- **iOS**: لا يدعم منبّهاً صوتياً مستمراً كأندرويد. الحل الحالي: إشعارات متكررة + Push،
  وCritical Alerts يتطلب موافقة Apple الخاصة (موثق للمستخدم داخل «صحة المنبّه»).
- **الويب المغلق**: setTimeout لا يعمل بعد إغلاق التبويب — الموثوقية عبر Web Push/FCM عند ضبط المفاتيح.
- **أدوية**: التطبيق لا يخترع أي بيانات دوائية؛ تعبئة الباركود تقرأ ما هو مكتوب فعلاً (GS1/العلبة)،
  وجدول `gtins` يتعلّم من تأكيداتك ويمكن ملؤه من مصدر مرخّص توفّره لاحقاً.

## قائمة اختبار القبول (يدوية)

1. **الأوضاع والمنبّه**: جهازان بنفس رمز الدعوة — جهاز «والدة» يرنّ منبّه لكل جرعة،
   جهاز «مالك» يستقبل إشعاراً صامتاً؛ عند نفاد دواء هام يصل المالك تنبيه عاجل بصوت.
2. **الحذف والاسترجاع**: احذف دواءً → Snackbar مع تراجع 10ث؛ احذف عرضاً → يطلب تأكيداً؛
   السلة تعرض كل المحذوفات مع استرجاع فردي/جماعي.
3. **المخزون**: أضف رصيداً (60 قرصاً) → تفصيل علب/شرائط/أقراص؛ خذ جرعات → خصم تلقائي؛
   البطاقة تعرض أيام متبقية ملونة وتاريخ نفاد متوقع.
4. **الباركود**: امسح علبة GS1 (أو أدخل `01062810090019281727093010ABC123` يدوياً) →
   يُعبّأ GTIN والانتهاء والتشغيلة؛ حفظ يتطلب مراجعتك؛ الربط يتعلّم في `gtins`.
5. **AI**: أضف تقرير تحليل → «طلب ملخص» يطلب موافقة → الملخص يُحفظ مع بند التحليل
   مع التنبيه الدائم «ليس تشخيصاً طبياً»؛ الشات يشرح المصطلحات بلا أي توصية جرعات.
6. **المزامنة**: سجّل جرعة على جهاز بلا إنترنت → ظهور شارة المعلّقات → عند العودة تتزامن
   وتصل إشعارات «أُخذت الجرعة» للأجهزة الأخرى.
